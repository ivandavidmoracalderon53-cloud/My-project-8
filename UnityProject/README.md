# Pasillo 14 — Unity

Proyecto base 3D para Unity 6000.2.5f1. Escenarios construidos con geometría 3D y personajes 2D en billboard con sprites procedurales animados. No requiere assets externos.

## Abrir
Abre la carpeta `UnityProject` desde Unity Hub. Al primer inicio deja que Unity resuelva el paquete UGUI. Ejecuta `Pasillo14 > Crear escena jugable` para generar y abrir `Assets/Scenes/Pasillo14.unity`, luego pulsa Play. El proyecto usa la entrada clásica (`Input.GetAxisRaw`) para WASD y flechas; si el asistente de migración de Input System aparece, conserva la entrada antigua.

## Controles
WASD/flechas: moverse · E: entregar tarea al siguiente compañero · Espacio: lanzar bola de papel distractora · V: impulso Viva 87 · Esc: pausa.

## Contenido
Pasillo universitario con salones, casilleros, baños, cámaras y patrulla de la profesora. Personajes ilustrados siguiendo la referencia: Ratchet Dunkold, Flaky Peaceday, Khaterine Fieldgar, Bernie Hopper y Ms. Beatriz Clawster. Relevos, tres dificultades y trofeos por completar.
